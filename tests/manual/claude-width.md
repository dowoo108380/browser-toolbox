# claude.ai에서 대화 열·작성란 너비(CLD-1) 확인

자동 시험은 2026-10-20에 사용자의 Chrome(로그인한 화면, 창 3072px)에서 구조만 보고 본뜬 시험 페이지(`tests/fixtures/claude.html`, 결정 0040)에서 돈다. 그때 보지 못한 것이 있다: 창이 768px보다 좁을 때의 실제 배치(창이 최대화되어 있어 크기를 바꾸지 못했다), 프로젝트 화면, 프로젝트 안의 대화. 이 절차로 실제로 쓰는 화면에서 확인한다. 화면 구조가 바뀌어 요소를 찾지 못하면 기능은 15초 뒤 "찾지 못함"을, 요소는 그대로인데 사이트가 너비를 정하는 방법(열 너비 변수, 새 채팅의 작성란 자리)을 바꿔 너비가 걸리지 않으면 "적용되지 않음"을 보이도록 만들어져 있다(COM-6, 결정 0034). 그때는 아래 "찾지 못함이나 적용되지 않음이 나오면"대로 구조만 뽑아 알린다.

## 준비

- `pnpm verify`를 통과한 빌드(`dist/`)를 정식 Chrome에 올린다(`tests/manual/smoke-chrome.md`의 1–2단계). 이미 올려 두었으면 `chrome://extensions`에서 그 확장의 다시 불러오기(↻)를 누르고, 열려 있던 claude.ai 탭을 새로 고친다.
- 평소 쓰는 Chrome 프로필에서 claude.ai에 로그인해 둔다. 이 확장은 대화 내용을 읽거나 밖으로 보내지 않는다(페이지에 스타일 요소 하나를 넣고, 정해 둔 요소가 있는지와 그 그려진 너비만 본다).
- 창을 1600px보다 넓게 둔다(정한 너비 1200px이 원래 너비보다 넓어 보이도록).
- 메시지가 여러 개이고 긴 답이 있는 대화 하나를 고른다. 이 절차는 메시지를 보내지 않는다.

## 절차

1. 그 대화(`https://claude.ai/chat/…`)를 연다. 그 탭을 보는 채로 팝업을 열고 "Claude" 범주를 고른다.
   - 기대(결정 0029): "대화 열·작성란 너비"에 "쓸 수 없음"이 보이지 않는다. 스위치는 "꺼짐", 아래 "최대 너비(px)" 칸에 `1200`이 있다.
2. 스위치를 켠다.
   - 기대(CLD-1.1): 새로 고침 없이 대화의 메시지 열과 아래 작성란이 함께 넓어진다. 둘의 왼쪽·오른쪽 끝이 맞고 가운데에 놓인다. 긴 답의 글줄이 길어진다.
3. 팝업의 칸에 `1600`을 쓰고 Enter, 이어서 ↑를 두 번 누른다.
   - 기대(CLD-1.1, 결정 0030): Enter에 열과 작성란이 1600px로, ↑마다 10px씩 넓어진다(팝업을 닫지 않아도 탭에 바로 보인다).
4. 칸에 `500`을 쓰고 Enter를 누른 뒤 Esc를 누른다.
   - 기대: Enter에 "640–3840 사이의 정수만 쓸 수 있어 저장하지 않았다."가 보이고 페이지는 그대로다. Esc에 칸이 저장된 값(1620)으로 돌아간다.
5. 옆 메뉴에서 다른 대화를 연다. "새 채팅"을 누른다. 프로젝트를 쓰면 프로젝트 안의 대화도 하나 연다(메시지는 보내지 않는다).
   - 기대(CLD-1.2): 어느 대화에서든 정한 너비가 그대로다. 새 채팅 화면에서는 작성란이 그 너비다(사이트의 원래 너비 640px보다 넓다). 프로젝트 안의 대화도 주소가 `/chat/…`이면 같다.
   - 프로젝트 화면 자체(`/project/…`)는 이 기능이 기대하지 않는 화면이다. 넓어지든 아니든 괜찮고, 6단계처럼 기다려 "찾지 못함"이 나오지 않으면 된다.
6. 대화 화면과 새 채팅 화면에서 각각 20초 넘게 기다린 뒤 팝업을 다시 연다.
   - 기대(COM-6, CLD-1.5, CLD-1.6, 결정 0040): "찾지 못함"도 "적용되지 않음"도 보이지 않는다. 이것이 실제 화면의 구조와 너비 규칙이 본뜬 것과 맞는지 보는 단계다.
7. 창을 좁힌다(예: Windows 키 + ←로 화면의 반).
   - 기대(CLD-1.3): 열과 작성란이 창에 맞춰 줄고 가로 스크롤 막대가 생기지 않는다.
8. **창을 768px보다 좁게 한다**(2026-10-20에 보지 못한 배치). 창의 오른쪽 가장자리를 끌어 더 좁히거나, 개발자 도구(F12)의 기기 툴바(Ctrl+Shift+M)에서 너비를 700으로 둔다. claude.ai가 옆 메뉴를 숨기거나 다른 배치로 바꿀 수 있다.
   - 기대(CLD-1.3): 대화 화면과 새 채팅 화면 모두 열과 작성란이 창에 맞고 가로 스크롤 막대가 없다. 그 너비에서 다른 대화를 열고, 새 채팅도 열어 각각 20초 넘게 기다린 뒤 팝업을 다시 열어도 "찾지 못함"도 "적용되지 않음"도 보이지 않는다(CLD-1.6). 보이면 아래 "찾지 못함이나 적용되지 않음이 나오면"을 그 너비에서 한다.
9. 창을 넓게 되돌리고 스위치를 끈다.
   - 기대(CLD-1.4): 새로 고침 없이 열과 작성란(새 채팅 화면의 작성란 포함)이 켜기 전 너비로 돌아간다.
10. "ChatGPT" 범주의 "대화 열·작성란 너비"를 켜고 끈다. claude.ai가 아닌 탭(예: 뉴스 사이트)에서 팝업의 "Claude" 범주를 연다.
    - 기대(CLD-1.7, 결정 0029): ChatGPT의 스위치와 칸을 바꿔도 claude.ai 탭의 너비는 바뀌지 않는다. 다른 사이트의 탭에서는 "쓸 수 없음: claude.ai에서만 쓸 수 있음"이 보인다. 칸과 스위치는 그대로 쓸 수 있다(모든 탭에 대한 설정).

## 찾지 못함이나 적용되지 않음이 나오거나 너비가 바뀌지 않으면

실제 화면의 구조가 본뜬 것과 다르다는 뜻이다. 대화 내용 없이 구조만 뽑아 알린다.

1. 그 화면에서 작성란을 한 번 누른다(초점을 둔다).
2. F12로 개발자 도구를 열고 "Console"에 아래를 붙여 넣고 Enter를 누른다. 요소의 종류, 속성 이름(값은 `role`만), 배치, 그려진 너비와 최대 너비만 나온다. 글, 주소, 대화 제목, 속성의 값은 나오지 않는다.

   ```js
   (() => {
     const describe = (element) => {
       const style = getComputedStyle(element);
       const names = [...element.attributes]
         .map((attribute) => attribute.name)
         .filter((name) => name !== 'class' && name !== 'style');
       const role = element.getAttribute('role');
       const width = Math.round(element.getBoundingClientRect().width);
       return `${element.localName}${role ? `[role=${role}]` : ''} ${names.join(' ')} | ${style.display} | 너비 ${width} | 최대 ${style.maxWidth}`;
     };
     const upward = (start) => {
       const lines = [];
       for (
         let element = start;
         element && element !== document.body;
         element = element.parentElement
       ) {
         lines.push(describe(element));
       }
       return lines.join('\n');
     };
     const middle = document.elementFromPoint(innerWidth / 2, innerHeight / 3);
     console.log(
       `[창 ${innerWidth}px]\n[작성란에서 위로]\n${upward(document.activeElement)}\n\n[화면 가운데에서 위로]\n${upward(middle)}`,
     );
   })();
   ```

3. 나온 글을 [GitHub Issues](https://github.com/dowoo108380/browser-toolbox/issues)의 결함 양식에 붙인다(Chrome 버전, 확장 버전, 사이트 `claude.ai`, 화면 언어, 몇 단계에서 무엇이 보였는지, 창 너비). 그 구조로 `src/sites/claude/`의 단서와 너비 규칙을 고친다(결정 0040 다시 볼 조건).
