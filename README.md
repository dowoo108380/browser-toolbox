# Browser Toolbox

웹을 쓰는 동안 늘 켜 두는 Chrome 확장이다. 미디어 배속, YouTube, 자막, 탭, 페이지, ChatGPT, Claude 도구를 팝업 하나에 모은다.

> **개발 중이다.** 아래 22개 기능 가운데 지금 쓸 수 있는 것은 배속 표시창(일부), 페이지 활성 상태 유지, ChatGPT와 Claude의 대화 열·작성란 너비 넷이고, 나머지는 차례로 더한다. 릴리스와 Chrome 웹 스토어 판은 아직 없으므로 직접 빌드해서 불러온다.

- 미디어의 네 기능은 팝업에서 "미디어 배속" 스위치 하나로 함께 켜고 끈다. 지금은 배속 표시창의 일부만 있다: 켜면 화면에 그려진 가로·세로가 모두 100px 이상인 영상의 왼쪽 위에 지금 배속(예: `1.5×`)을 보인다. 배속을 바꾸는 조작, 표시창 옮기기, `V`로 숨기기는 예정이다. 확장이 처음 살펴본 뒤에 붙는 shadow root나 닫힌 shadow root 안의 영상에는 표시창이 나타나지 않을 수 있고, 늦게 붙은 열린 root는 기능을 껐다 켜면 찾는다(위험 N-17).
- ChatGPT와 Claude의 "대화 열·작성란 너비"는 서로 다른 기능이다. 스위치와 너비를 따로 정한다.
- "페이지 활성 상태 유지"는 다른 기능과 달리 탭마다 켜고 끈다(아래 "쓰는 법").
- YouTube와 자막 기능은 `www.youtube.com`의 시청 화면(`/watch`)이 대상이다.

## 설치

1. 아래 "직접 빌드하기"의 1–3단계로 `dist/`를 만든다.
2. Chrome에서 `chrome://extensions`를 열고 오른쪽 위의 "개발자 모드"를 켠다.
3. "압축 해제된 확장 프로그램을 로드합니다"를 누르고 저장소의 `dist` 폴더를 고른다.
4. 설치하기 전부터 열려 있던 탭은 새로 고쳐야 확장이 동작한다. 새로 연 탭에서는 바로 동작한다.

### 업데이트

1. 새 코드를 받고(`git pull`) 다시 빌드한다(`pnpm install`, `pnpm build`).
2. `chrome://extensions`에서 Browser Toolbox 카드의 다시 로드 단추(↻)를 누른다. 설정은 그대로 남는다.
3. 열린 탭을 새로 고친다. 다시 로드하면 열린 탭에서 돌던 옛 판은 멈추며 자기가 바꾼 것을 치우므로(예: ChatGPT 너비가 원래대로 돌아감), 그 탭을 새로 고치거나 다른 페이지로 가야 새 판이 동작한다.

다시 로드는 처음 불러온 폴더를 다시 읽는다. 저장소를 다른 경로로 옮기거나 다른 폴더를 불러오면 Chrome은 그것을 다른 확장으로 보아 설정을 따로 둔다(처음처럼 모든 기능이 꺼져 있다).

### 지우기

확장을 지우면 Chrome이 그 확장의 설정도 함께 지운다. 설정의 백업과 복원은 설정 페이지와 함께 만들 예정이고, 그 전까지는 지운 뒤 다시 설치하면 모든 기능이 꺼진 처음 상태다. 업데이트할 때는 지우지 말고 위처럼 다시 로드한다.

## 쓰는 법

### 팝업 열기

Chrome 도구 모음의 확장 아이콘(퍼즐 모양)에서 Browser Toolbox를 누르면 팝업이 열린다. 압정 단추로 고정해 두면 도구 모음에서 바로 누를 수 있다. 팝업은 다른 곳을 누르면 닫힌다.

### 범주와 검색

- 왼쪽에 범주가, 오른쪽에 고른 범주의 기능이 보인다. 기능이 있는 범주만 보이므로 지금은 "미디어", "탭", "ChatGPT", "Claude"뿐이다. 팝업은 지난번에 고른 범주로 열린다.
- 범주 목록에서는 ↑·↓로 범주를 바꾸고, Home·End로 처음과 끝 범주로 간다.
- `Ctrl+K`를 누르면 팝업 어디서든 위쪽의 검색 칸으로 간다. 기능 이름이나 설명의 일부를 쓰면 맞는 기능만 보인다. ↑·↓로 고르고 Enter를 누르면 그 기능으로 가서 스위치에 초점이 놓이므로, 이어서 Space로 켜고 끌 수 있다. Esc는 검색어를 지운다.

### 켜고 끄기

- 기능마다 스위치가 있다. 켜고 끄는 것은 모든 탭에 대한 설정이고(탭마다 켜는 "페이지 활성 상태 유지"는 아래), 이미 열린 탭에도 새로 고침 없이 바로 적용된다. 끄면 그 기능이 페이지에 더한 것(표시창, 스타일)이 사라지고 페이지가 원래대로 돌아간다.
- "대화 열·작성란 너비"(ChatGPT와 Claude 범주에 하나씩)는 스위치 아래 "최대 너비(px)" 칸에서 너비를 정한다. 640–3840 사이의 정수이고 처음 값은 1200이다. Enter를 누르거나, 다른 곳으로 초점을 옮기거나, ↑·↓(10px씩)를 누르면 저장되어 열린 그 사이트(chatgpt.com, claude.ai)의 탭에 바로 걸린다. 대화 화면의 대화 열과 작성란, 새 채팅 화면의 작성란이 그 너비가 된다. 창이 그보다 좁으면 창 너비에 맞춘다. 범위 밖의 값은 저장하지 않고 이유를 보이며, Esc를 누르면 저장된 값으로 돌아간다.
- 저장하지 못하면 팝업 아래쪽에 알림이 뜨고, 스위치와 칸은 저장된 값으로 돌아간다.
- 팝업 아래쪽에 "저장된 설정을 읽을 수 없어 … 기본값으로 바꿨다"가 보이면 그 설정이 손상되어 처음 값으로 돌아간 것이다. 필요하면 다시 정하고 "확인"을 누른다.

### 페이지 활성 상태 유지

다른 탭을 보거나 창을 최소화해도, 켜 둔 탭은 화면에 보이는 탭처럼 동작한다. 영상과 강의가 멈추지 않고, 타이머와 작업이 느려지지 않고, 자리 비움으로 로그아웃되지 않게 한다.

- 팝업의 "탭" 범주에서 "이 창의 탭" 목록의 고르는 칸으로 탭을 하나 또는 여럿 고르고 "고른 탭 켜기"나 "고른 탭 끄기"를 누른다. 목록은 팝업을 연 창의 탭이고, 탭마다 "켜짐"·"꺼짐"과 안 되는 이유가 보인다. 확장 아이콘에는 아무것도 표시하지 않는다.
- "모든 탭" 스위치를 켜면 지금 열린 탭과 앞으로 여는 탭이 모두 켜지고, 끄면 모두 꺼진다. 스위치를 바꾸면 탭마다 따로 켜고 끈 것은 지워진다. 스위치가 켜진 동안에도 목록에서 탭 하나를 끄거나 다시 켤 수 있다.
- 탭마다 켠 것은 그 탭을 닫거나, 확장을 다시 로드하거나, Chrome을 다시 켜면 꺼진다. "모든 탭" 스위치는 설정이라 남고, 켜져 있으면 그 뒤에도 열린 탭에 작용한다. 켠 탭에서 다른 페이지로 가도 켜진 채다.
- 웹 페이지(http·https)에서만 쓴다. Chrome 내부 화면, 새 탭, 내 컴퓨터의 파일, Chrome 웹 스토어는 "쓸 수 없음: 웹 페이지에서만 쓸 수 있음"이다. 켠 탭이 그런 화면으로 가면 그동안 쉬고, 웹 페이지로 돌아오면 다시 동작한다.
- 확장을 설치하거나 업데이트(다시 로드)하기 전부터 열려 있던 탭은 목록에 "쓸 수 없음: 이 탭을 새로 고쳐야 쓸 수 있음"이 보인다. 그런 탭은 켜져 있어도 새로 고치기 전에는 일부만 동작한다(다른 프로그램을 쓰는 동안의 초점, 가려진 창 알기, 마우스 움직임이 없다). 확장이 들어갈 수 없는 웹 페이지(오류 화면 등)는 "쓸 수 없음: 확장이 이 페이지에 접근할 수 없음"이다. 목록의 이 이유는 "탭" 범주를 열 때 한 번 확인한다.
- 켠 탭은 Chrome이 메모리를 아끼려고 비우지 않고, 끄면 원래대로 돌아간다.
- 탭을 보지 않는 동안(다른 탭 뒤, 최소화한 창, 다른 창에 완전히 가려진 창) 확장은 그 탭에 Chrome 디버거를 붙여 초점이 있는 것처럼 둔다. 화면에 보이는 탭에는 붙이지 않는다(붙이면 전체 화면이 탭 안에서만 되고 NVIDIA RTX Video가 꺼진다). 다른 프로그램을 쓰는 동안 화면에 보이는 켠 탭은 페이지가 초점이 있다고 여기게 한다.
- 입력이 없는 것으로 자리 비움을 판단하는 사이트를 위해, 보지 않는 켠 탭에 1분마다 마우스 움직임 하나를 보낸다. 링크·버튼·입력란·메뉴·영상이 없는 빈 곳에만 보내고, 그런 곳이 없으면 보내지 않고 목록에 이유를 보인다. 클릭이나 키 입력은 보내지 않는다. 서버가 시간이 지나 세션을 끊는 것은 막지 못한다.
- 이유가 보이면:

  | 문구                                | 뜻                                                                                                          | 할 일                                                |
  | ----------------------------------- | ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
  | 디버거를 붙이지 못해 껐다. …        | 페이지 안에 다른 확장이 넣은 화면(비밀번호 관리자 등)이 있거나 보안 경고 화면이라 Chrome이 디버거를 막았다. | 그 화면이 없어진 뒤 다시 켠다.                       |
  | 디버깅 안내 막대에서 취소해 껐다. … | 안내 막대의 "취소"를 눌러 켜진 탭이 모두 꺼졌다("모든 탭" 스위치 포함).                                     | 다시 켜면 다시 붙인다.                               |
  | 가짜 입력을 보낼 안전한 곳이 없어 … | 화면 전체가 버튼 같은 것으로 덮여 마우스 움직임을 보내지 않는다. 기능은 켜진 채다.                          | 없음. 그 페이지에서는 자리 비움을 막지 못할 수 있다. |

- 한계: 다른 창에 **일부만** 가려진 창의 탭은 보는 탭으로 보아 마우스 움직임을 보내지 않는다. 창을 덮은 프로그램을 치우기만 하고 Chrome 창을 누르지 않으면, 누를 때까지 그 탭은 전체 화면이 탭 안에서만 되고 RTX Video가 꺼진다.

#### 디버깅 안내 막대 숨기기

보지 않는 켠 탭에 디버거가 붙어 있는 동안 Chrome은 모든 창 위에 "Browser Toolbox에서 이 브라우저를 디버깅하는 중" 같은 안내 막대를 하나 띄운다. 확장은 이 막대를 숨기지 못한다. 숨기려면 Chrome을 `--silent-debugger-extension-api` 옵션으로 켠다.

1. Chrome을 모두 닫는다(작업 표시줄 오른쪽의 Chrome 아이콘도 끝낸다).
2. Chrome을 켜는 바로 가기(바탕 화면이나 작업 표시줄)를 오른쪽 단추로 누르고 "속성"을 연다. 작업 표시줄의 것은 오른쪽 단추 → "Google Chrome"을 다시 오른쪽 단추 → "속성"이다.
3. "바로 가기" 탭의 "대상" 끝(`…\chrome.exe"` 뒤)에 한 칸 띄고 `--silent-debugger-extension-api`를 붙인다. 예: `"C:\Program Files\Google\Chrome\Application\chrome.exe" --silent-debugger-extension-api`
4. "확인"을 누르고 그 바로 가기로 Chrome을 켠다.

**보안 주의**: 이 옵션으로 켠 Chrome에서는 이 확장뿐 아니라 디버거 권한이 있는 **다른 확장도 알림 없이** 디버거로 탭을 읽고 바꿀 수 있다. 믿는 확장만 설치한 Chrome에서 쓴다. 옵션은 그 바로 가기로 켤 때만 적용되고, 다른 방법(다른 바로 가기, 링크를 눌러 켜짐 등)으로 켠 Chrome에는 적용되지 않는다. 그만 쓰려면 "대상"에서 옵션을 지운다.

### 쓸 수 없다는 문구

지금 탭에서 기능을 쓸 수 없으면 그 기능의 설명 아래에 이유가 보인다. 스위치는 그래도 쓸 수 있다(모든 탭에 대한 설정이다). "페이지 활성 상태 유지"의 탭 목록에도 탭마다 같은 문구가 보인다.

| 문구                                          | 뜻                                                                                     | 할 일                    |
| --------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------ |
| 쓸 수 없음: 확장이 이 페이지에 접근할 수 없음 | Chrome 내부 페이지(`chrome://…`)나 Chrome 웹 스토어처럼 Chrome이 확장을 막는 페이지다. | 일반 웹 페이지에서 쓴다. |
| 쓸 수 없음: 이 탭을 새로 고쳐야 쓸 수 있음    | 확장을 설치하거나 업데이트(다시 로드)하기 전부터 열려 있던 탭이다.                     | 그 탭을 새로 고친다.     |
| 쓸 수 없음: (사이트)에서만 쓸 수 있음         | 그 사이트(chatgpt.com, claude.ai) 전용 기능을 다른 사이트의 탭에서 열었다.             | 그 사이트의 탭에서 쓴다. |

### "찾지 못함"이나 "적용되지 않음"이 보이면

외부 사이트(chatgpt.com, claude.ai 등)는 화면을 자주 바꾼다. 그래서 사이트의 화면에 기대는 기능은 일이 어긋나면 조용히 실패하지 않고 그 기능의 설명 아래에 알린다.

- **찾지 못함: (요소 이름)**: 사이트가 화면 구조를 바꿔, 기능이 기대는 요소(예: "ChatGPT 대화 열")를 15초 안에 찾지 못했다.
- **적용되지 않음: (요소 이름)**: 요소는 찾았지만 사이트가 모양을 정하는 방법을 바꿔, 15초 뒤에 보니 기능이 건 변경(예: 너비)이 걸려 있지 않았다.

어느 쪽이든 확장은 그 탭에서 그 기능만 멈추고 기능이 바꾼 것을 되돌린다. 페이지는 사이트의 원래 모습으로 쓸 수 있고, 다른 기능은 그대로 동작한다. 15초는 탭이 보이는 동안의 시간만 센다.

1. 탭을 새로 고치거나, 같은 사이트의 다른 화면(다른 대화, 새 채팅 등)으로 가거나, 스위치를 껐다 켠다. 기능이 처음부터 다시 시작한다. 찾지 못함은 그 요소가 나중에 나타나도 저절로 다시 동작한다.
2. 팝업은 열 때의 상태를 보이므로, 팝업을 다시 열어 문구가 사라졌는지 본다.
3. 계속 보이면 확장을 고쳐야 한다. 아래 "문제 알리기"대로 알리고, 보인 문구(요소 이름 포함)를 그대로 적는다.

## 지원 환경

- Windows의 데스크톱 Chrome 150 이상(manifest의 `minimum_chrome_version`과 같다)
- 화면 문구는 한국어다.
- Chrome 웹 스토어에는 올리지 않는다. 직접 빌드해 "압축 해제된 확장"으로 불러온다.

## 권한과 개인정보

| 권한                        | 쓰는 곳                                                                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `storage`                   | 설정을 저장한다.                                                                                                                                             |
| `scripting`                 | 팝업을 열 때 지금 탭에서 확장이 동작하는지 확인하고, 확장을 다시 로드하거나 갱신했을 때 열린 탭에 남은 옛 스크립트에게 정리하라고 알린다.                    |
| `http://*/*`, `https://*/*` | 기능이 http·https 페이지와 그 안의 프레임에서 동작한다: 영상의 배속 표시와 페이지 활성 상태 유지(모든 사이트), 대화 열·작성란 너비(chatgpt.com, claude.ai).  |
| `debugger`                  | 페이지 활성 상태 유지: 켠 탭을 보지 않는 동안에만 그 탭에 붙어 초점이 있는 것처럼 두고, 1분마다 빈 곳에 마우스 움직임을 보낸다. 페이지의 내용은 읽지 않는다. |

확장은 스스로 외부 서버에 데이터를 보내지 않는다.

## 문제 알리기

결함과 요청은 [GitHub Issues](https://github.com/dowoo108380/browser-toolbox/issues)에 양식으로 남긴다. 결함 양식은 Chrome 버전, 확장 버전, 사이트, 재현 절차를 묻는다. 이슈는 누구나 볼 수 있으므로 개인정보와 로그인한 화면의 내용은 넣지 않고, 사이트는 도메인만 적는다.

## 직접 빌드하기

[Git](https://git-scm.com/)과 [pnpm](https://pnpm.io/installation) 12가 있으면 된다. Node.js는 pnpm이 저장소에 적힌 판(`package.json`의 `devEngines`)을 받아 쓴다.

1. 저장소를 짧은 경로에 받는다.

   ```powershell
   git clone https://github.com/dowoo108380/browser-toolbox.git C:\src\browser-toolbox
   cd C:\src\browser-toolbox
   ```

2. 의존성을 받는다. 테스트용 Chromium도 저장소 안(`node_modules`)에 받는다.

   ```powershell
   pnpm install
   ```

3. 빌드한다. `dist/`에 압축 해제된 확장이 생긴다.

   ```powershell
   pnpm build
   ```

Windows의 경로 길이 제한(260자) 때문에 저장소는 짧은 경로(대략 100자 이하)에 둔다. 경로가 길면 테스트용 Chromium이 실행되지 않는다(`spawn UNKNOWN`).

고칠 때 쓰는 명령:

| 명령            | 하는 일                                                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| `pnpm check`    | 빌드 없이 빠르게 검사한다: 타입, 린트, 서식, 구조 규칙, 안 쓰는 코드, 단위·DOM 테스트.                         |
| `pnpm format`   | 서식을 고친다.                                                                                                 |
| `pnpm generate` | 기능을 더하거나 뺀 뒤 진입점별 등록 목록을 다시 만든다.                                                        |
| `pnpm verify`   | CI와 같은 검사 전체: `check`에 더해 빌드, 확장 전체 테스트, 배포 ZIP까지. 고친 것을 올리기 전에 통과해야 한다. |

## 구조 개요

```text
src/
  shared/      순수 도구(결과 값, 오류 종류, 제한 시간이 있는 기다림, 여러 기능이 함께 쓰는 계산)
  contracts/   메시지 정의, 기능 정의의 타입, 검증 어휘
  platform/    chrome.* API를 감싸는 경계와 테스트용 가짜
  storage/     설정 저장 형식, 형식 이전, 설정 읽기 도우미
  dom/         웹 페이지 위 화면 틀(닫힌 shadow root), 페이지 스타일, 자원 범위, 외부 화면 요소 찾기
  sites/       외부 사이트(chatgpt.com, claude.ai)의 화면 지식
  page/        콘텐츠 스크립트 실행 틀과 기능이 함께 쓰는 페이지 쪽 일
  background/  서비스 워커(메시지 라우터, 설정 쓰기, 작업 기록, 문제 기록, 탭마다 켜고 끄기, 디버거 관리)
  ui/          확장 화면(Preact)
  features/    기능 하나 = 폴더 하나. features/list.ts가 기능 목록
  entries/     진입점(서비스 워커, 팝업, 콘텐츠 스크립트, 페이지의 세계 스크립트)과 기능 목록에서 만든 등록 목록
scripts/       빌드, 등록 목록 생성, 패키징
tests/         확장 전체 테스트(e2e), 모듈 연결 시험(integration), 시험 페이지(fixtures), 설정 표본(samples), 수동 확인 절차(manual)
```

- 층의 방향: 목록에서 아래에 있는 층이 위에 있는 층을 쓰고, 거꾸로는 쓰지 않는다(위의 층을 모두 쓰는 것은 아니다). 순환도 없다. 규칙은 `.dependency-cruiser.json`에 있고 `pnpm check`가 검사한다.
- 기능끼리는 서로 가져오지 않는다. 기능 사이에 필요한 것은 `contracts`와 공용 층을 거친다.
- 외부 사이트의 화면 지식(요소를 찾는 단서, 모양을 바꾸는 규칙)은 `src/sites/<사이트>/` 한 곳에만 둔다. 사이트가 화면을 바꾸면 그곳을 고친다.
- 설정은 `chrome.storage.local`의 `settings` 키 하나에 두고, 쓰는 곳은 서비스 워커 한 곳이다. 팝업과 페이지는 읽기만 하고, 바꿀 때는 서비스 워커에 요청한다.
